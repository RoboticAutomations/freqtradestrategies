# Organization

## Why it changed

The repository was a single directory holding 586 `.py` files, including
duplicates named `HurstCycleV5 (2).py` and `Ichimoku_v12 (copy).py`. Finding
anything meant already knowing its filename.

Files are now grouped by **strategy family**. Family is decided by filename
first (`NostalgiaForInfinityX5.py` → `nostalgia-for-infinity/`), and where the
name says nothing useful, by the indicators the parser actually found in the
source. 289 files
matched neither and sit in `uncategorized/`.

## Rules used

- **Deduplication.** Files with identical SHA-256 were collapsed to one copy,
  515 in total. The surviving copy prefers the repository's own
  version, then a direct download, then a file recovered from a zip archive.
- **Naming.** Telegram message-id prefixes (`19763_`) and `(copy)` / `(2)`
  suffixes were stripped. Where two genuinely different files then collided, the
  later one gains a `__2` suffix.
- **Hyperopt parameters.** A `<Strategy>.json` next to a `<Strategy>.py` is a
  Freqtrade parameter file and was moved *with* the strategy, not into
  `configs/`. 133 files travelled this way.
- **Permissions.** Everything is written `0644`. Nothing in this repository is
  marked executable.
